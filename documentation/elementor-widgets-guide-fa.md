# راهنمای المنتور و ویجت‌های ولنتو شاپ

این راهنما برای صاحب فروشگاه نوشته شده، نه برای برنامه‌نویس. اگر افزونه‌ی
رایگان **Elementor** روی سایت شما فعال باشد، قالب ولنتو شاپ به‌صورت خودکار
یک دسته‌ی ویجت اختصاصی به نام **«ولنتو شاپ»** به پنل المنتور اضافه می‌کند
که شامل ۲۲ ویجت آماده برای ساخت صفحه است.

## پیش‌نیاز

1. افزونه‌ی **Elementor** را از پیشخوان وردپرس > افزونه‌ها > افزودن، نصب
   و فعال کنید. (نیازی به نسخه‌ی Pro نیست؛ همه‌ی ۲۲ ویجت با نسخه‌ی رایگان
   کار می‌کنند.)
2. یک صفحه بسازید یا صفحه‌ی موجود را باز کنید و روی «ویرایش با المنتور»
   بزنید.
3. در پنل سمت راست/چپ، دسته‌ی «ولنتو شاپ» را در لیست ویجت‌ها پیدا کنید.

## لیست ویجت‌ها

| ویجت | کاربرد |
|---|---|
| اسلایدر هیرو | بخش اصلی بالای صفحه با تصاویر برند در حال چرخش |
| کاروسل ساعت‌های منتخب | ردیف افقی از محصولات یا موارد منتخب |
| گرید محصولات | نمایش خودکار محصولات فروشگاه (جدید، ویژه، حراج، پرفروش یا یک دسته خاص) |
| معرفی محصول ویژه | نمایش بزرگ یک محصول با تصویر و قیمت زنده |
| عنوان بخش | یک عنوان و توضیح ساده بین بخش‌های صفحه |
| بنر دعوت به اقدام | تصویر + متن + دکمه، مناسب معرفی یک کالکشن |
| بنر تمام‌عرض | پس‌زمینه‌ی تمام‌عرض تصویر یا ویدیو با متن روی آن |
| نوار خدمات و تضمین‌ها | چند آیتم با آیکن (ضمانت اصالت، ارسال، گارانتی...) |
| ردیف نشان‌های اعتماد | نسخه‌ی فشرده‌تر همان نشان‌ها برای پایین صفحه محصول |
| عضویت در خبرنامه | فرم ایمیل، متصل به همان سیستم خبرنامه‌ی سایت |
| نوار اعلان | یک خط پیام بالای صفحه (مثلاً کد تخفیف) |
| لوگوی برندها | ردیف لوگوهای برندهای موجود در فروشگاه |
| تصویر و متن | بخش دو ستونه‌ی معرفی/داستان برند |
| نظرات مشتریان | اسلایدر نظرات با امتیاز ستاره‌ای |
| سوالات متداول | آکاردئون پرسش و پاسخ |
| گرید مطالب وبلاگ | آخرین نوشته‌های وبلاگ سایت |
| نوار دسته‌بندی‌ها | کارت‌های تصویری برای دسته‌بندی محصولات (مردانه/زنانه و...) |
| آمار و اعداد | اعداد شمارشی (مثلاً «۵۰۰۰+ مشتری راضی») |
| تایمر شمارش معکوس | برای پایان یک جشنواره فروش |
| دکمه | یک دکمه‌ی ساده با سه استایل |
| فرم تماس ساده | فرم نام/ایمیل/تلفن/پیام که به ایمیل مدیر سایت ارسال می‌شود |
| نقشه و آدرس فروشگاه | نقشه‌ی گوگل (اختیاری) + کارت آدرس و تلفن و ساعات کاری |

## تغییر پالت رنگی

دو راه برای اعمال پالت رنگی دلخواه‌تان وجود دارد:

### روش ۱ — پالت رنگی کل سایت (پیشنهادی)
از مسیر **پیشخوان > نمایش > شخصی‌سازی > پالت رنگی ولنتو** پنج رنگ اصلی
سایت (تاکیدی/پس‌زمینه/متن/متن کم‌رنگ/خط جداکننده) را تنظیم کنید. این
رنگ‌ها هم روی کل سایت و هم روی همه‌ی ویجت‌های المنتور اعمال می‌شود و
به‌طور خودکار در «رنگ‌های عمومی» (Global Colors) خود المنتور هم با
پیشوند «ولنتو —» ظاهر می‌شود تا در هر ویجت دیگری هم قابل انتخاب باشد.

### روش ۲ — رنگ اختصاصی برای یک بخش خاص
هر یک از ۲۲ ویجت، در تب «استایل» یک بخش به نام **«پالت رنگی ولنتو»**
دارد. اگر آنجا رنگی انتخاب نکنید، همان ویجت از پالت سراسری سایت پیروی
می‌کند. اگر رنگی انتخاب کنید، فقط همان یک ویجت رنگش عوض می‌شود — بدون
اینکه روی بقیه‌ی سایت اثر بگذارد. این گزینه برای مواقعی مناسب است که
مثلاً می‌خواهید یک بنر تبلیغاتی رنگ متفاوتی از بقیه‌ی صفحه داشته باشد.

## نکات مفید

- «گرید محصولات» و «معرفی محصول ویژه» اطلاعات را زنده از ووکامرس
  می‌خوانند؛ نیازی به وارد کردن دستی قیمت یا موجودی نیست.
- برای «معرفی محصول ویژه»، شناسه‌ی عددی محصول را از پیشخوان > محصولات
  (روی محصول موردنظر ماوس ببرید، عدد کنار «ID:» را کپی کنید) وارد کنید.
- برای «نقشه و آدرس فروشگاه»، از گوگل‌مپ روی «اشتراک‌گذاری > جاسازی
  نقشه» بزنید و فقط آدرس داخل `src="..."` را کپی و در فیلد نقشه بچسبانید.
- اگر افزونه‌ی Elementor Pro هم نصب باشد، از مسیر **Templates > Theme
  Builder** می‌توانید هدر، فوتر، قالب تک‌محصول و قالب آرشیو فروشگاه را
  هم با المنتور بازطراحی کنید؛ قالب ولنتو شاپ از این قابلیت پشتیبانی
  می‌کند.
