# Marketplace Release Checklist

## Before Upload

- [ ] Test fresh WordPress installation
- [ ] Test WooCommerce installation
- [ ] Test desktop layout
- [ ] Test mobile layout
- [ ] Test RTL pages
- [ ] Check product page
- [ ] Check cart
- [ ] Check checkout
- [ ] Check account page
- [ ] Remove debug files
- [ ] Prepare screenshots
- [ ] Prepare demo content
- [ ] Prepare product description
- [ ] Prepare support information

## Package
Do not include:
- backups
- logs
- development files
- temporary files
